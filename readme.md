# ISAC System Based on Clustering Algorithm for Multipath Environments - Compatible with MATLAB Code

The summary of the OFDM-ISAC system, which is based on clustering algorithms and suitable for multipath environments, has garnered attention due to its ability to achieve perception, localization, and communication simultaneously by sharing wireless resources and signal waveforms. Orthogonal Frequency Division Multiplexing (OFDM) remains a core technology in next-generation mobile communication systems due to its robustness against multipath fading and its good support for high-rate data. This paper introduces a novel OFDM-ISAC technology based on orthogonal sequences (OS), which is fully compatible with traditional OFDM communication systems. It cleverly utilizes the autocorrelation properties of orthogonal sequences and the spectral efficiency of index modulation, while also integrating clustering algorithms to solve technical challenges in multipath environments. Extensive computer simulations have verified that even in the absence of line-of-sight (LOS) links, this OFDM-ISAC system can achieve reliable communication and positioning performance in real multipath environments.
Introduction The International Telecommunication Union Radio Communications Sector (ITU-R) conference in 2023 released the IMT-2030 framework, which clarified the application scenarios and key performance indicators for next-generation mobile communication systems. Integrated Perception and Communication (ISAC) systems have become one of the core application scenarios for 6G mobile communication. This system can support both communication and perception functions simultaneously within the same frequency band and hardware. It achieves target detection and positioning through communication signals or transmits information via radar signals.
Existing research has proposed various ISAC-related technologies, such as joint subcarrier power allocation, serial interference cancellation, and transmit beamforming. However, traditional ISAC systems often face compatibility issues with traditional communication systems or require additional receiving structures to achieve simultaneous communication and perception. Meanwhile, as the core technology for next-generation communication, OFDM creates new opportunities for high-frequency ISAC service deployment. Research has attempted to integrate perception functions into traditional OFDM systems, but most rely on line-of-sight links, making it difficult to achieve in high-frequency communication environments.
To this end, this paper proposes a novel OFDM-ISAC system that can simultaneously achieve data detection and user positioning in the uplink communication process between a single user device and a base station without requiring line-of-sight links. The system employs an index modulation method using orthogonal sequences, with the base station utilizing multi-antennas and the autocorrelation properties of orthogonal sequences to perform direction finding and ranging. It incorporates a density-based clustering algorithm to enhance performance. Finally, the system's communication and positioning capabilities are validated through bit error rate (BER) and root mean square error (RMSE).
Method Introduction: This paper designs an OFDM-ISAC system for uplink communication architecture, consisting of base stations equipped with uniform linear array (ULA) multi-antenna and single antenna user equipment (UE), using a local scattering channel model without line-of-sight links, focusing only on multipath signals and external interference. The core method revolves around the orthogonal sequence (OS), integrating index modulation, multi-antenna signal processing, and DBSCAN density clustering algorithm to achieve integrated communication and positioning capabilities. The overall process and key technologies are as follows:
1  
Orthogonal sequence and index modulation design: Cycle shift the original orthogonal sequence to generate candidate sequences, map information bits to candidate sequence indices, and realize the conversion of bits to orthogonal sequences. After being processed by OFDM standards such as DFT, IFFT, and insertion of cyclic prefix (CP), the signals are transmitted by the user equipment, and the base station completes pre-processing tasks such as CP removal and FFT.
2  
Sequence detection and demodulation: The base station calculates the correlation value between the received signal and the orthogonal sequence, identifies the index corresponding to the maximum correlation value, combines multi-antenna spatial diversity, and uses the mode of majority among the antenna detection results as the final sequence index to complete bit demodulation, thereby realizing communication functions.
3  
Distance and Direction Estimation: Based on the difference between the maximum correlation value index and the detection sequence index, calculate the distance between the user and the base station; Utilizing array antenna-related methods, the arrival angle (AoA) of signals is estimated through the correlation operation between despread signals and a spatial dictionary, thereby achieving preliminary positioning.
4  
DBSCAN clustering improves positioning accuracy: To address the issues of multipath and interference in unline-of-sight links, features such as estimated distances, arrival angles, and signal power are collected. After data normalization and power threshold screening, the DBSCAN density clustering algorithm groups effective signal features into one category and classifies interference features as noise. The minimum distance in the clustering results is used as the final ranging value, and the average arrival angle in the clustering results is used as the final directional value to achieve high-precision positioning. 
The system is verified through MATLAB simulations, selecting three orthogonal sequences: ZC sequence, m sequence, and Gold sequence, and setting up simulation conditions such as 6-bit index modulation and local scattering multipath (including 20% external interference). It analyzes the communication performance and positioning performance of different sequences under different system bandwidth conditions. 
Conclusion: This paper proposes an OFDM-ISAC system that can simultaneously achieve communication and wireless positioning. The system integrates index modulation and the autocorrelation characteristics of orthogonal sequences, effectively working even in an environment without line-of-sight (LOS) links. Computer simulation results show that this OFDM-ISAC system is fully compatible with traditional OFDM communication systems and can ensure robust performance in both communication and perception tasks. 
Future research plans will expand this system to multiuser or mobile user scenarios, further analyzing its performance in complex scenarios to provide more comprehensive technical support for the practical application of ISAC technology in 6G communication.
